# Mathector 0.17.0

发布日期：2026-10-07。原生 Android 高中数学题集 App，最低 Android 8.0。

## 本次改动

圆角气泡使用独立配色：白天浅蓝 #E4EDFF、黑夜灰蓝 #334463，与页面及卡片形成清晰色差。覆盖选题的年级／知识点／难度、题库年级与题目操作、题集排序／移除、导出格式和自定义知识点模块菜单。继续保留 24 dp 圆角，无外阴影或外描边；默认选中蓝色在白天调整为 #285DCF，保留分类色及原有动效。

工程首次发布到公开 GitHub 仓库 [SACO1F/Mathector](https://github.com/SACO1F/Mathector)。本地初始化 main 分支，提交完整源码、Gradle Wrapper、Room schema、文档和测试。历史开发记录保留在 README，初次源码导入没有重建此前版本的提交历史。
