# Mathector 0.19.0

发布日期：2026-10-07。原生 Android 高中数学题集 App，最低 Android 8.0。

## 本次改动

- 题集模块的“我的题集”标题、副标题及右上角创建入口固定在系统状态栏下方，卡片在下方独立滚动；滑到列表末尾后，三个元素仍保持可见和原位。
- 创建入口改为 Apple 风格“＋ 创建”圆角胶囊：柔和浅蓝底、细蓝边、蓝色图标与文字，48 dp 触摸高度，轻微按压缩放与弹簧回弹。白天／黑夜分别配色，仍打开原有圆角创建窗口，保留名称校验、键盘确认与取消操作。

源码已同步到公开仓库 [SACO1F/Mathector](https://github.com/SACO1F/Mathector)，默认分支 main，版本标签 v0.19.0。
