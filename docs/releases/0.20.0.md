# Mathector 0.20.0

发布日期：2026-10-07。原生 Android 高中数学题集 App，最低 Android 8.0。

## 本次改动

- 独立公式输入区增加实时 LaTeX 校对预览，接受裸公式与已有数学分隔符，格式有误时给出校对提示。专用区域明确标注“不参与导出”；不会追加到题目正文预览、题库／题集／选题卡片或练习 PDF／Word。需要导出的公式请放入题干。去除空题干时的独立公式导出兜底，提示补充题干后再导出，保留现有独立公式数据。
- 共用题目卡片同时显示橙色“待校对”或绿色“已校对”；题库新增“已校对”筛选。题目只有显式确认后才标记已校对，修改标题、题干或分类后重新待校对，只修改独立公式或自动解题开关不改变校对状态。顶部和保存提示说明当前状态。
- 校对／编辑及手动录入页的返回、标题、校对状态和圆角确认入口固定在系统状态栏下方；内容在下方独立滚动，键盘弹出时仍能看到并操作顶部入口，白天／黑夜适配。保留草稿自动保存和底部确认按钮，仅填写独立公式无法确认已校对。

源码同步到公开仓库 [SACO1F/Mathector](https://github.com/SACO1F/Mathector)，默认分支 main，版本标签 v0.20.0。
