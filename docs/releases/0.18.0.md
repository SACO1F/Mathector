# Mathector 0.18.0

发布日期：2026-10-07。原生 Android 高中数学题集 App，最低 Android 8.0。

## 本次改动

- 移除题库首页“每一道好题，都有自己的位置。”大标题及其占用的空白，保留品牌、简短说明、统计、搜索与筛选入口。
- 题集详情的题集名称与返回按钮固定在系统状态栏下方，题目和文档设置在下方独立滚动。滚到最底部仍可直接返回；长名称最多两行，超出省略，适配白天／黑夜。悬浮添加按钮、底部连续滚动及导出入口间距保留。

源码已同步到公开仓库 [SACO1F/Mathector](https://github.com/SACO1F/Mathector)，默认分支 main，版本标签 v0.18.0。

- CollectionGlassTest：长题集名称在白天／黑夜均固定在页面顶部；滚动中和连续划到底后标题区域及返回按钮坐标不变，返回按钮可直接回到题集列表；题目列表位于标题下方且延伸到页面底部，添加按钮固定并避开系统导航区，最后的 PDF／Word 操作完整可见。继续验证主页面三个模块的加号和选题分类气泡。
