# 题库备份与恢复

从 Mathector 0.21.0 起，可在题库右上角“题库备份”，或“我的 → 题库导入与导出”中导出和导入完整题库。

## 使用

1. 点击“导出题库”，在 Android 文件选择器中选择下载文件夹、用户文件目录或云盘并保存 ZIP。
2. 保存成功后保留 ZIP 文件。应用私有目录会随卸载清除，系统文件选择器选定的公共目录或云盘文件可在重新安装后继续选择。
3. 重新安装 Mathector 0.21.0 或支持相同备份版本的后续版本，点击“导入题库”选择 ZIP。
4. 查看数据数量并点击“导入题库”。恢复完成后，题目与题集立即显示。识别接口需重新配置。

题集导出的 PDF／Word 用于练习与打印，恢复题库请选择这里生成的完整 ZIP 备份。

## 数据范围

| 数据 | 备份与恢复行为 |
| --- | --- |
| 题目 | 保留编号、标题、正文、子题、独立公式、分类、来源说明与创建时间 |
| 标记 | 保留待校对／已校对、收藏与示例标记 |
| AI 解答 | 保留答案、公式、错误提示及单题自动解题开关；有效答案重建指纹，过期答案继续保留但不作为有效答案展示 |
| 原图 | 将仍可读取的原图写入 ZIP，按 SHA-256 内容去重；恢复为新路径，保留图像字节 |
| 题集 | 保留名称、题目关联与顺序，以及试卷标题、说明、时间和满分 |
| 知识点 | 合并用户创建的高中数学知识点；同名知识点保留当前本机模块 |
| 接口与应用偏好 | 不包含接口地址、模型名、API Key、主题偏好或全局自动解题偏好 |
| 后台任务与记录 | 不备份或重启识别／解题任务，不导入任务记录 |

同编号题目与题集保留本机已有版本。新题集可以关联本机已有题目；已存在的题集不变更设置或顺序。重复导入同一份备份不新增重复记录。若需要最新改动，请在改动完成后重新导出一份备份。

## 格式与校验

备份为标准 ZIP，包含一个 `manifest.json` 及被题目引用的 `sources/<SHA-256>.<扩展名>` 原图。文字清单的格式标识为 `MathectorLibraryBackup`，格式版本为 1；不包含设备绝对路径或数据库文件。图片扩展名限定为 jpg、jpeg、png、webp、heic、heif、img。

导入前检查格式与版本、唯一编号、题集引用及排序、知识点名称、文件路径、文件 CRC 和原图 SHA-256。多余文件、缺图、重复编号、越界路径、错误格式或不支持的版本会拒绝导入；不会直接解压外部提供的路径。原图在导出前已不存在的情况通过清单统计及界面提示区别处理，文字仍可恢复。

当前限制：ZIP 和解压内容总大小分别不超过 512 MB，单张原图不超过 50 MB，文字清单不超过 32 MB，题目最多 20,000 道，题集最多 5,000 个，关联最多 100,000 条，自定义知识点最多 5,000 个。超限会显示具体提示，不截断数据。

导出先完成私有临时文件，再写入所选位置；完成、取消或失败后清理临时备份。导入预览不写入题库；确认后的新增题目、题集和顺序在单个数据库事务中写入，失败时回滚记录、此次新增知识点及原图。不会覆盖本机已有题目、题集或识别配置。
